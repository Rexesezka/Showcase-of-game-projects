# Витрина игровых проектов

Веб-сайт для демонстрации студенческих игровых проектов: каталог игр, карточки проектов, запуск Unity WebGL билдов, страница для экспертов с формой заявки.

Проект состоит из двух частей:

| Часть | Технологии | Адрес после запуска |
|-------|------------|---------------------|
| **Бэкенд** (API, админка, файлы) | Django, SQLite | http://127.0.0.1:8000 |
| **Фронтенд** (сайт) | Next.js, React | http://localhost:3000 |

Для работы сайта нужно запустить **оба** сервера одновременно.

---

## Что установить заранее

Установите на компьютер (если ещё не установлено):

1. **Python 3.10 или новее**  
   Скачать: https://www.python.org/downloads/  
   При установке отметьте галочку **«Add Python to PATH»**.

2. **Node.js 20 LTS или новее** (вместе с ним установится `npm`)  
   Скачать: https://nodejs.org/

Проверка в терминале (PowerShell или «Командная строка»):

```bash
python --version
node --version
npm --version
```

Все три команды должны вывести номер версии без ошибки.

## 1. Бэкенд (Django)

Откройте терминал в папке проекта и выполните команды по порядку.

### 1.1. Перейти в папку бэкенда

```bash
cd backend
```

### 1.2. Создать виртуальное окружение (рекомендуется)

**Windows (PowerShell):**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Windows (CMD):**

```cmd
python -m venv venv
venv\Scripts\activate.bat
```

После активации в начале строки терминала появится `(venv)`.

### 1.3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 1.4. Применить миграции базы данных

```bash
python manage.py migrate
```

### 1.5. Создать учётную запись администратора

Нужна для входа в админ-панель и управления проектами.

```bash
python manage.py createsuperuser
```

Введите логин, email (можно пропустить) и пароль.

### 1.6. Запустить сервер

```bash
python manage.py runserver
```

Оставьте этот терминал **открытым**. Бэкенд работает по адресу: **http://127.0.0.1:8000**

Админ-панель: **http://127.0.0.1:8000/admin/**

---

## 2. Фронтенд (Next.js)

Откройте **второй** терминал (бэкенд не закрывайте).

### 2.1. Перейти в папку фронтенда

```bash
cd frontend
```

(Если вы в `backend`, сначала вернитесь: `cd ..`, затем `cd frontend`.)

### 2.2. Установить зависимости

```bash
npm install
```

Выполняется один раз при первом запуске (может занять несколько минут).

### 2.3. Настройка адреса бэкенда (по желанию)

По умолчанию фронтенд обращается к `http://127.0.0.1:8000`. Если бэкенд на другом порту, создайте файл `frontend/.env.local`:

```env
BACKEND_URL=http://127.0.0.1:8000
```

### 2.4. Запустить сайт

```bash
npm run dev
```

Сайт откроется по адресу: **http://localhost:3000**

---

## 3. Проверка

1. Откройте в браузере **http://localhost:3000** — главная страница с проектами.
2. Откройте **http://127.0.0.1:8000/admin/** — войдите логином и паролем из `createsuperuser`.
3. В админке добавьте **Сезон**, затем **Проект** (описание, оценку, изображения, ZIP билда, команду, артефакты Git/Figma).
4. Обновите главную страницу — проект должен появиться в списке.

## Работа с админ-панелью (кратко)

| Раздел | Назначение |
|--------|------------|
| **Сезоны** | Периоды (например, «Весна 2026») |
| **Проекты** | Игры: описание, оценка, билд, фото, команда, ссылки |
| **Заявки** | Заявки с страницы «Экспертам» — одобрить или отклонить |

### Изображения для карточки

- **Файл изображения** — загрузить картинку с компьютера (рекомендуется).
- **Ссылка на файл** — необязательно, только публичный URL вида `https://...` (не путь `C:\Users\...`).

### Запуск игры

1. В проекте загрузите **ZIP архив билда** (Unity WebGL с `index.html`).
2. Сохраните проект — ссылка на билд заполнится автоматически.
3. На сайте нажмите **ИГРАТЬ** на странице проекта.

## Частые проблемы

### «python не является внутренней командой»

Python не добавлен в PATH. Переустановите Python с галочкой **Add Python to PATH** или укажите полный путь, например:

```bash
py -m pip install -r requirements.txt
py manage.py runserver
```

### Сайт открывается, но проектов нет / пустая страница

- Убедитесь, что **бэкенд запущен** (`python manage.py runserver` в папке `backend`).
- Проверьте, что в админке есть хотя бы один проект.

### Картинки не отображаются

- Для обложки лучше использовать **загрузку файла** в админке, а не ссылку с диска Windows.
- Бэкенд должен быть запущен — файлы отдаются с `http://127.0.0.1:8000/media/...`.

### Игра не запускается

- В админке должен быть загружен ZIP с Unity WebGL и заполнено поле **Ссылка на билд**.
- Пересохраните проект после загрузки архива.

### Ошибка при `npm install` или `npm run dev`

- Проверьте версию Node.js: `node --version` (нужна 18+).
- Удалите папку `frontend/node_modules` и снова выполните `npm install`.

### PowerShell не даёт активировать venv

Выполните один раз (от имени администратора):

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

## Запуск для продакшена (кратко)

Для демонстрации заказчику на своём ПК достаточно режима разработки выше.

Для постоянного хостинга потребуется отдельная настройка (сервер, домен, `DEBUG=False`, PostgreSQL, сборка фронта `npm run build` + `npm start`, настройка статики и медиа). Это выходит за рамки локального запуска.

## Контакты и поддержка

При проблемах с запуском проверьте, что оба терминала работают без ошибок, и повторите шаги из разделов 1 и 2.
